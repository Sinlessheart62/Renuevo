# Renuevo

Juego de restauración ecológica en 3D, con una isla flotante de estilo pintado a mano: sana el suelo, crea ecosistemas, registra la fauna y vete sin dejar huella. Cuatro regiones: valle templado, archipiélago tropical, tundra helada y caldera volcánica.

Se juega en el navegador y se puede instalar en el iPhone desde Safari con **Compartir → Agregar a pantalla de inicio**. Funciona sin conexión.
